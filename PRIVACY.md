## 1. Overview
Crib Ready Publisher is a proprietary content creation and publishing application used exclusively by the **@CribReady** team to create, manage, and publish original educational pregnancy, maternity, and newborn videos and guides to our official social media channels, including Pinterest Business.

## 2. Information We Access via Pinterest API
When authorized via official Pinterest OAuth 2.0 consent, the application accesses only the permissions explicitly granted (`boards:read`, `pins:read`, `pins:write`, `user_accounts:read`) in order to:
- Display our owned Pinterest account handle and boards inside the local Crib Ready Studio dashboard.
- Upload original short-form educational videos (`POST /v5/media`) and create Video Pins (`POST /v5/pins`) linking to Crib Ready guides.

## 3. Data Storage, Security & Sharing
- **Local-only credential storage:** OAuth access tokens and refresh tokens are stored strictly in a local access-controlled configuration file on the operator's workstation solely to automate publishing to `@CribReady`'s own channels.
- **No third-party data collection or resale:** We do not collect, track, sell, rent, or share personal data of external users, visitors, or third-party Pinterest accounts.
- **No external advertising tracking:** The desktop/local publishing studio does not serve third-party ads or analytics trackers.

## 4. Data Retention & Revocation
OAuth access can be revoked at any time via **Pinterest Settings -> Security & Logins / Connected Apps** (`pinterest.com/settings/security/`) or directly inside the Crib Ready Studio interface using **Disconnect**, which immediately clears locally stored tokens. To request data deletion or ask privacy questions, email **luigisjob@gmail.com**.
